# Bakbak Lyrics

Bakbak Lyrics is a full-stack, community-driven platform for creating and playing **syllable-level synced lyrics** for Spotify songs. Users can search any track on Spotify, sync its lyrics in a purpose-built editor while the song plays, and then watch the result in an animated karaoke-style player that highlights each syllable as it's sung. It supports lead, background and duet vocals, so complex songs display the way they're actually performed.

## 📁 Project Structure

The project is a single Next.js 14 application (App Router) with server actions and an Appwrite backend:

```text
.
├── app/
│   ├── editor/      # Lyric sync editor (import, syllabification, voice separation, timing)
│   ├── player/      # Karaoke-style lyrics player with queue and search sidebar
│   ├── song/[id]/   # Song pages by ISRC (sync status, lyrics preview, contributors)
│   ├── login/       # Email/password auth, Spotify OAuth2 and password reset flows
│   └── components/  # Shared UI (navbar, account dropdown, inputs, blurred album background)
├── actions.ts       # Next.js server actions (search, upload, auth)
├── appwrite.ts      # Appwrite server client: auth, sessions, database and Spotify token logic
└── utils.ts         # Lyric processing for the player (voice grouping, line timing)
```

### 1. `app/editor/` — Lyric Sync Editor
A multi-step editor for turning plain lyrics into precisely timed, syllable-level data.

* **Lyric import:** paste or write raw lyrics.
* **Automatic syllabification:** splits words into syllables using the CMU Pronouncing Dictionary, the `syllable` library and a custom vowel-pattern heuristic, with manual correction afterwards.
* **Voice separation:** a click-and-drag "brush" to tag each word as lead, background or duet vocals.
* **Real-time syncing:** the song plays through the Spotify Web Playback SDK while the user taps the spacebar on each syllable; holding the key records sustained notes with an end time.
* **Smart workflow:** automatic switching between vocal tracks, rewinding clears timings past the playhead, and a seekable timeline with keyboard shortcuts.
* **Compact storage:** a custom compression format keeps synced lyrics small before uploading to the database.

### 2. `app/player/` — Karaoke Lyrics Player
An immersive, Apple Music-inspired playback experience.

* Per-syllable gradient "wipe" highlighting timed to each syllable's duration.
* Background vocals shown above or below the main line, and duet parts right-aligned.
* Depth-of-field blur on distant lines, subtle word lift animations and auto-scrolling to the active line.
* Animated, blurred album-art background.
* Sidebar with Spotify search (showing which songs are already synced) and a play queue with automatic track advancement.

### 3. Accounts & Song Pages
* Email/password authentication plus "Continue with Spotify" OAuth2 login, or connecting Spotify to an existing account.
* Secure, HTTP-only session cookies and automatic Spotify token refresh.
* Password reset via email recovery links.
* Song pages keyed by ISRC showing sync status, a lyrics preview, last update time and contributors.
* Role system (User, Contributor, Expert, Admin) with badges.

## 🛠️ Tech Stack & Key Technologies

* **Framework:** Next.js 14 (App Router, Server Actions), React 18, TypeScript
* **Database & Auth Services:** Appwrite (Auth, Databases, Users)
* **Styling & Animations:** Tailwind CSS, Framer Motion, custom CSS karaoke effects
* **Integrations:** Spotify Web API (search, track metadata, OAuth2) and Spotify Web Playback SDK
* **Language Processing:** CMU Pronouncing Dictionary, `syllable`

> Note: playback and syncing use the Spotify Web Playback SDK, which requires a Spotify Premium account.
